# Student Login Page

A beginner-friendly, responsive login page project made with HTML, CSS, and JavaScript.

## Features
- Email and password fields
- Basic email and password validation
- Show/hide password button
- Remember me checkbox
- Responsive layout for mobile and desktop
- Demo messages for forgot password and registration links

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

## Important Note
This is a front-end student demo only. It does not authenticate users, store passwords, create accounts, or connect to a database. Do not enter a real password.
